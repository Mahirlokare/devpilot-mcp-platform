# DevPilot Security Architecture & Threat Model

DevPilot treats every external repository, source file, issue, pull request, database row, log line, and OpenAPI specification as **untrusted input**.

## 1. Defense-in-Depth Controls

| Threat | Control Implemented | Code Location |
|---|---|---|
| **Credential leakage to LLM or UI** | Secrets are loaded from environment variables or Fernet-encrypted database columns (`credentials.token_encrypted`, `mcp_servers.env_encrypted`). API responses return `env_keys` names only, never values. All tool outputs and audit logs pass through regex secret redaction (`redact()` / `audit.scrub()`). | `backend/app/security.py`, `backend/app/services/audit.py`, `mcp_servers/common/guards.py` |
| **Unauthorized write or destructive AI actions** | Every MCP tool call goes through `invoke_tool_with_policy`. Non-builtin servers are never trusted to self-declare `readOnlyHint=True`. All `write` and `destructive` tools create a database `Approval` row (`status="pending"`) and halt execution until a developer or admin explicitly approves. | `backend/app/services/policy.py`, `backend/app/services/tool_gateway.py` |
| **Prompt Injection via untrusted tool output** | Tool results passed to the LLM are wrapped in `<untrusted_tool_result>` tags with system-prompt instructions forbidding the model from following embedded commands, and crucially, **policy enforcement is performed in deterministic Python code outside the LLM**, so a compromised prompt still cannot bypass RBAC or human approval. | `backend/app/services/orchestrator.py`, `backend/app/services/policy.py` |
| **Path Traversal & Host Filesystem Exposure** | `resolve_in_root` resolves symlinks and verifies `resolved.relative_to(root)`, rejecting absolute paths, drive letters, NUL bytes, and `..` escapes. Secret-looking filenames (`.env*`, `*.pem`, `*.key`, `id_rsa*`, `.git/config`, `credentials.json`) are blocked from reading and writing. | `mcp_servers/common/guards.py`, `mcp_servers/filesystem/server.py` |
| **Command Injection & Arbitrary Code Execution** | `terminal` and `testing` MCP servers never invoke a shell (`create_subprocess_exec` with `argv` list). Executables must match the allowlist (`python`, `pytest`, `pip`, `ruff`, `node`, `npm`, `npx`, `git`, `tsc`). Interpreter eval flags (`python -c`, `node -e/--eval/--require`, `git -c/--upload-pack`) and write git subcommands are blocked. Production requires `DEVPILOT_TERMINAL_SANDBOX=docker` (`--network none --read-only --cap-drop ALL --security-opt no-new-privileges --pids-limit 256`). | `mcp_servers/terminal/runner.py` |
| **SQL Injection & Database Mutation** | The `database` MCP server validates that each query is a single statement starting with `SELECT`/`WITH`/`EXPLAIN`/`VALUES`, strips comments/literals to block stacked queries (`;`) and disallowed tokens (`INSERT`, `UPDATE`, `DELETE`, `DROP`, `PRAGMA`, `ATTACH`, `COPY`, `pg_sleep`, `lo_import`), and opens the underlying SQLite connection with `mode=ro` + `PRAGMA query_only=ON` (or PostgreSQL `BEGIN READ ONLY` + `ROLLBACK`). | `mcp_servers/database/server.py` |
| **Server-Side Request Forgery (SSRF)** | `assert_public_url` resolves DNS via `socket.getaddrinfo` and blocks private, loopback, link-local, multicast, and cloud metadata (`169.254.169.254`, `metadata.google.internal`) addresses. `apidocs` validates every redirect hop manually (max 3 hops). | `mcp_servers/common/guards.py`, `mcp_servers/apidocs/server.py` |
| **Authentication & Session Security** | Passwords hashed with `hashlib.scrypt` (`N=16384, r=8, p=1`) and verified with `hmac.compare_digest`. JWTs pinned to `HS256` with required `exp` and `sub`. Sliding-window rate limiting on auth (`10/min`) and API (`120/min`) endpoints. GitHub OAuth uses single-use cryptographic `state` tokens stored in `oauth_states`. | `backend/app/security.py`, `backend/app/deps.py`, `backend/app/api/routes.py` |
| **XSS via untrusted tool results** | The React frontend renders all tool outputs, logs, code snippets, and errors as escaped text nodes (`<pre>`, `<code>`, table cells) and never uses `dangerouslySetInnerHTML`. | `frontend/src/components/*` |
